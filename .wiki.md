# Project Summary
The E-commerce System is a comprehensive platform that enhances online retail operations through advanced features such as product management, order processing, customer engagement, and review handling. It employs a Java backend utilizing a Binary Search Tree (BST) structure, a Python API for data interactions, and a React frontend for a user-friendly experience. This architecture ensures high performance and scalability, catering to both users and administrators.

# Project Module Description
- **Java Core**: Implements the application logic with a focus on BST-based data structures and services for products, customers, and orders.
- **Python API**: Provides a RESTful interface for managing data interactions related to customers, products, and orders.
- **Frontend (Shadcn UI)**: A modern React-based user interface designed for seamless user interactions with the e-commerce platform.

# Usage
1. **Install Dependencies**:
   - For the Java backend, use Maven or Gradle to manage dependencies.
   - For the Python API, run `pip install -r requirements.txt` to install required packages.
   - For the frontend, use `pnpm install` or `npm install`.

2. **Build the Project**:
   - For the Java application, run the build command specific to your build tool (e.g., `mvn package` or `gradle build`).
   - For the frontend, run `pnpm run build`.

3. **Run the Application**:
   - Use the `start.sh` script to build and start all services, or manually use Docker Compose commands to bring up the environment.
